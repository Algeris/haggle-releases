# Haggle

> Never lose a negotiation again.

Haggle is Algeris' AI-powered negotiation intelligence platform.

It helps you understand what's happening during a negotiation, identify leverage, recognize important signals, and make better decisions when the conversation actually matters.

## Download

The latest version of Haggle is available from the [Releases](../../releases) page.

## What Haggle does

- Real-time negotiation intelligence
- Conversation analysis
- Strategic recommendations
- Negotiation memory
- Deal and risk intelligence
- AI-powered response suggestions
